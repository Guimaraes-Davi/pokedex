# Pokédex

Projeto de portfolio desenvolvido em Python.
Consome a PokeAPI para buscar e exibir informações sobre pokémons.

## Acesse online
https://pokedex-3yck.onrender.com

## Tecnologias
- Python
- Flask
- SQLite
- PokeAPI

## Funcionalidades
- Busca de pokémons com autocomplete
- Visualização de stats e tipos
- Sistema de favoritos com persistência em banco de dados

## Como rodar localmente
```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python run.py
```
